# LeetCode in Java

Repository with my solutions to [LeetCode](https://leetcode.com/) problems, written in **Java**.

The goal is to practice programming logic, data structures and algorithms, while keeping a record of my progress.

## Tech Stack

- Java 21
- Maven (Maven Wrapper included)

## Organization

Each problem lives in its own package inside `src`, with a `Solution` class following the same format used by LeetCode.

```
src/main/java/
├── leetcode/                              # LeetCode solutions (DSA Track)
│   └── <ProblemName>/
│       ├── Solution.java
│       └── instruction.md
└── com/example/leetcode/javaBasicsTraining/  # Java language practice (Java Track)
    └── STUDY_PLAN.md
```

## Study Plan

This repository follows a structured roadmap to go from **Java basics to advanced** and get ready for **technical interviews**. It has two tracks that run in parallel:

- **Java Track** — the language, JVM, concurrency, testing, design patterns and Spring Boot
- **DSA Track** — LeetCode problems grouped by pattern (arrays, hashing, two pointers, trees, graphs, DP...)

| Phase | Java Track | DSA Track |
|-------|------------|-----------|
| 1 | Fundamentals | Arrays & Strings |
| 2 | Object-Oriented Programming | Stacks |
| 3 | Exceptions, Generics & Collections | Hashing, Two Pointers, Sliding Window |
| 4 | Functional Java & Modern Features (8 → 21) | Binary Search, Linked Lists |
| 5 | JVM Internals & Memory | Trees |
| 6 | Concurrency & Multithreading | Heaps, Backtracking |
| 7 | Testing, Design Patterns & Clean Code | Graphs |
| 8 | Backend Ecosystem (Spring Boot) | Dynamic Programming |
| 9 | Advanced & Interview Ready | Advanced Problems & Mock Interviews |

👉 See the full plan with checklists in [STUDY_PLAN.md](src/main/java/com/example/leetcode/javaBasicsTraining/STUDY_PLAN.md).
